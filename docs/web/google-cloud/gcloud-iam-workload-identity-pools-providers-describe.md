# gcloud iam workload-identity-pools providers describe

Google's page has no Markdown source, so this page holds, in Codeman's words, only what Codeman's documentation relies on; each fact names the section of the page it comes from.

## Synopsis

```
gcloud iam workload-identity-pools providers describe (PROVIDER : --location=LOCATION --workload-identity-pool=WORKLOAD_IDENTITY_POOL) [GCLOUD_WIDE_FLAG …]
```

## Facts

- Prints one provider, named by its ID with `--workload-identity-pool` and `--location`, or by its full name (POSITIONAL ARGUMENTS, EXAMPLES).
- The project comes from the full name, from `--project`, or from the `core/project` property (POSITIONAL ARGUMENTS).
- It also takes the flags every `gcloud` command takes, among them `--project`, `--format` and `--flatten` (GCLOUD WIDE FLAGS).
