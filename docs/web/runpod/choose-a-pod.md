# Choose a Pod

What Codeman relies on, in its own words.

## Secure Cloud and Community Cloud

From "Secure Cloud vs Community Cloud":

| | Secure Cloud | Community Cloud |
| --- | --- | --- |
| Hosts | T3/T4 data centers | Peer-to-peer providers |
| Reliability | High redundancy | Variable |
| Runpod recommends it for | Production and sensitive data | Cost-sensitive workloads |
| Price | Standard | Lower |

- Runpod no longer accepts new Community Cloud hosts, and the existing hosts stay available (the note under the table).
- RTX PRO 6000 MIG slices are on Secure Cloud only (the note in the GPU list).
