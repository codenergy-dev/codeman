# gh variable list

The manual's pages have no Markdown source, so this page holds, in Codeman's words, only what Codeman's documentation relies on; each fact names the section of the page it comes from. Checked against release v2.102.0, the latest when recorded.

## Facts

- Lists the variables of a repository (the default), an environment or an organization (`-o`, `--org`) (description, Options).
- `--json` prints the chosen fields; a variable's are `createdAt`, `name`, `numSelectedRepos`, `selectedReposURL`, `updatedAt`, `value` and `visibility` (Options, JSON Fields).
