# v0.31.0

What Codeman relies on, in its own words: the release notes are larger than the repository should hold (45 KB). Released on 2026-10-05; each fact names the section it comes from.

## Images and CUDA

- The default Docker image, `vllm/vllm-openai:v0.31.0`, and the default wheels are built with CUDA 13.0; `vllm/vllm-openai:v0.31.0-cu129` is built with CUDA 12.9 ("Release Artifacts", "Docker Images"). Earlier releases also published `-ubuntu2404` variants of both ("Release Artifacts" of v0.30.0).
- A separately tagged image compressed with zstd (`-x86_64-zstd`) is published, and CUDA 12 images use LMCache 0.4.4 and CuPy for CUDA 12 ("Dependencies").
- FlashInfer 0.7.0.post1, Transformers 5.17.0, XGrammar 0.2.7 ("Dependencies").

## Starting faster

- `--enforce-eager` now also turns off the JIT kernel warmup, unless fault tolerance is on ("Highlights", "Breaking Changes & Deprecations").
- Triton's warmup compiles in parallel, and allocator fragmentation no longer shrinks the K/V cache during profiling ("Startup and memory").
- New and experimental: `vllm preload`, a daemon that keeps quantized weights in GPU memory across engine restarts, and `vllm snapshot create/restore`, which restores an initialized engine with CRIU, for one GPU ("Highlights", "Fast restart").

## Scheduling and hybrid models

- `--max-num-active-seqs` caps the requests running at once, apart from `max_num_seqs`; the waiting queue schedules first the requests that already hold K/V blocks ("Highlights", "Scheduling controls").
- Prefix caching for hybrid models: prompt-tail hits with MTP restored, and MTP draft K/V cache groups handled on the hybrid grouping path; `--enable-mamba-fine-grained-prefix-cache` is renamed `--enable-mamba-shared-prefix-checkpoint` ("Prefix caching and hybrid models", "Breaking changes").

## Security

- Per-request `mm_processor_kwargs` and `media_io_kwargs` are refused unless `--trust-request-mm-kwargs` is set; prefix-cache keys from a LoRA name and from a `cache_salt` can no longer collide ("Highlights", "Security").
